# How to Greet Users

> Learn how to greet users with Chatbot Studio.

## Quick Start

Add a greeting as the first message users see in your flow, then test it end-to-end in Studio.

## Steps

  1. Open **Studio** and choose the chatbot/project you want to edit.

  2. Open your **Flow** and select the **Start** node (or the first node users hit).

  3. Add or edit the first **Message** to greet users.
    
    You can keep it simple (a single welcome message), or make it smarter by routing based on:
    - **Keywords** via **Automated Responses** (e.g., “Hi”, “Hello”, “Hey”)
    - **Intent Matching** for broader greeting patterns (e.g., variants/languages you support)

  4. **Save** your changes and **test** the flow to confirm the greeting shows up at the right time.
