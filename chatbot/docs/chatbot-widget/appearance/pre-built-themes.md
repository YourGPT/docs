# Pre-Built Themes

> Learn how to change the theme of your chat widget.

You can customize how your chatbot widget looks using our pre-made styles or your own CSS.

![Widget Style](/assets/chatbot/widget-style.png)

## Using Style Templates

<ol className="space-y-8 my-8 list-decimal list-inside">

<li className="space-y-3">
<span className="font-bold dark:text-gray-300 text-lg md:text-xl">Find a Style</span>

<div className="ml-6 space-y-2">

- Go to our [GitHub style gallery](https://github.com/YourGPT/chatbot-widget-templates)
- Browse available templates
- Click on the style you want to use
- Copy the CSS code

</div>
</li>

<li className="space-y-3">
<span className="font-bold dark:text-gray-300 text-lg md:text-xl">Add the Style</span>

<div className="ml-6 space-y-2">

- Open your YourGPT Dashboard
- Go to Chatbot → Widget → Branding
- Paste the CSS into the CSS field
- Click Save

</div>
</li>

<li className="space-y-3">
<span className="font-bold dark:text-gray-300 text-lg md:text-xl">Check Your Widget</span>

<div className="ml-6 space-y-2">

- Open your website or preview
- Make sure everything looks correct

</div>
</li>

</ol>

> **INFO:** You can modify these styles or create your own. See our [styling guide](/chatbot/customization/sdk/styling) for details.
