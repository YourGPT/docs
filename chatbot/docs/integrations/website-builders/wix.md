## Installation

Integrating YourGPT Chatbot with your Wix website is simple. Follow these steps:

<Steps>
  <Step title="Sign in to Wix">
    Log in to your Wix account.
  </Step>
  <Step title="Access the Website Editor">
    Open your website editor in Wix.
  </Step>
  <Step title="Navigate to Settings">
    From the editor, go to your website's dashboard and click on <b>Settings</b>.
  </Step>
  <Step title="Add Custom Code">
    In the Settings menu, select <b>Custom Code</b>. This allows you to embed scripts or HTML code.
  </Step>
  <Step title="YourGPT Chatbot Integration">
    Visit the YourGPT Chatbot integration page.<br />
    At the top of the screen, locate the <b>Scripts section</b> and copy the given code snippet.
  </Step>
  <Step title="Paste the Code">
    Return to the Wix dashboard <b>Custom Code</b> section and paste the copied code.
  </Step>
  <Step title="Save Changes">
    Make sure to save the changes made to the custom code section in Wix.
  </Step>
</Steps>

<Callout title="Congratulations!" type="success">
  Your chatbot is now integrated with your Wix website.
</Callout>

## Troubleshooting

Here are answers to some common Wix integration questions:

<AccordionGroup>
  <Accordion title="Why isn’t my chatbot showing up on my Wix website?">
    Make sure you pasted the code snippet in the correct section under Custom Code and saved your changes. Also, try refreshing your website and clearing your browser cache.
  </Accordion>
  <Accordion title="My chatbot appears, but it doesn't respond to messages. What should I do?">
    Confirm the code snippet was copied correctly without missing anything. If the chatbot is visible and not responding, review your throttling settings under Security Settings in the dashboard and make sure you have not reached your limit, Increase the limit also.
  </Accordion>
  <Accordion title="Can I customize where the chatbot appears on my Wix site?">
    Yes! You can adjust widget appearance and positioning directly from the Widget Settings in your YourGPT Dashboard.
  </Accordion>
  <Accordion title="How do I remove or update the chatbot code on Wix?">
    Go back to the Custom Code section in your Wix dashboard to edit or remove the script as needed. Save your changes and republish your site.
  </Accordion>
  <Accordion title="The widget is hidden behind other content or not clickable.">
    This can happen due to CSS or z-index conflicts. Adjust the widget’s z-index settings in your YourGPT dashboard and republish.
  </Accordion>
</AccordionGroup>
