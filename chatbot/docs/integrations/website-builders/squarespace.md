## Installation 

Integrating YourGPT Chatbot with your Squarespace website. Follow these simple steps:

<ol>
  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Sign in to Squarespace:</div>
    <ul>
      <li>Log in to your Squarespace account.</li>
    </ul>
  </li>

  <br />

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Open Website Editor:</div>
    <ul>
      <li>In the top left corner, select <code>EDIT</code>.</li>
    </ul>

    <div className="flex justify-center items-center rounded-md p-4">
      <img
        src="/assets/chatbot/squarespace/squarespace1.png"
        alt="Install"
        className="rounded-md object-contain w-full"
      />
    </div>
  </li>

  <br />

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Edit Footer:</div>
    <ul>
      <li>
        Scroll down until you see the <code>EDIT FOOTER</code> button, click on it. Now click on the
        <code> ADD BLOCK</code> button in the left-hand corner,.
      </li>
    </ul>

    <div className="flex justify-center items-center rounded-md p-4">
      <img
        src="/assets/chatbot/squarespace/squarespace2.png"
        alt="Install"
        className="rounded-md object-contain w-full"
      />
    </div>
  </li>

  <br />

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Add Embed Block:</div>
    <ul>
      <li>Then select the <code>Code</code> option.</li>
    </ul>

    <div className="flex justify-center items-center rounded-md p-4">
      <img
        src="/assets/chatbot/squarespace/squarespace3.png"
        alt="Install"
        className="rounded-md object-contain w-full"
      />
    </div>
  </li>

  <br />

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Edit Embed Block:</div>
    <ul>
      <li>Click to <code>Edit</code> and then select the <code>Code Snippet</code> option.</li>
    </ul>

    <div className="flex justify-center items-center rounded-md p-4">
      <img
        src="/assets/chatbot/squarespace/squarespace4.png"
        alt="Install"
        className="rounded-md object-contain w-full"
      />
    </div>
  </li>

  <br />

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">YourGPT Chatbot Integration:</div>
    <ul>
      <li>Visit the YourGPT Chatbot integration page.</li>
      <li>Copy the provided code snippet from the <code>Scripts section</code>.</li>
    </ul>
  </li>

  <br />

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Paste the Code:</div>
    <ul>
      <li>Paste the chatbot widget <code>Script</code> code into the Block.</li>
    </ul>
  </li>

  <br />

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Save Changes:</div>
    <ul>
      <li>Save your changes and then select <code>DONE</code>.</li>
    </ul>
  </li>
</ol>

The ChatBot’s chat widget should now appear on your website.
