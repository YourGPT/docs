# Bubble

> Add the GPT Chatbot to your Bubble app using an HTML element or a global header script.

Integrate YourGPT Chatbot into Bubble in just a few steps.

> **TIP:** Use the Bubble header option to load the chatbot on every page without repeating steps.

---

## Installation

  1. In the <a href="https://chatbot.yourgpt.ai/dashboard/" target="_blank" className="no-underline font-bold">YourGPT Dashboard</a>, go to <b>Integrations → Website Builders → Custom Website</b> and copy the JavaScript snippet.

  2. In the Bubble editor, drag an <b>HTML</b> element onto the page where you want the chatbot.

  3. Open the HTML element settings and paste the YourGPT snippet. Save the page.

  4. Click <b>Preview</b> to confirm the chatbot appears in your Bubble app.

  5. Deploy your Bubble app so the chatbot loads on every page.

> **SUCCESS:** Your chatbot should now appear in your Bubble app. If it’s not visible, review the troubleshooting tips below.

---

## Troubleshooting

  <details>
<summary>Why isn’t my chatbot showing up in Bubble?</summary>

Make sure you have pasted the code snippet in the correct place (HTML element or global header), saved changes, and deployed your app to live. Also, try refreshing your site and disabling any ad or script blockers.
</details>

  <details>
<summary>I see two chatbots on my Bubble page—why?</summary>

The script should only be added once—either via a single page’s HTML element or in the global header, not both. Remove any duplicate installs and redeploy.
</details>

  <details>
<summary>Chatbot is hidden or not clickable</summary>

This can happen due to z-index or CSS conflicts. Adjust your widget’s z-index and appearance directly in <b>Widget Settings</b> from your YourGPT Dashboard, then redeploy your app.
</details>

  <details>
<summary>Domain restriction or security issues</summary>

Double-check that your Bubble domain is whitelisted in your chatbot’s security settings on the YourGPT Dashboard so the widget will appear on your live site.
</details>
