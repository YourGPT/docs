# viaSocket

> Connect YourGPT Chatbot through viaSocket to automate across your apps.

<Callout title="viaSocket is a powerful workflow automation platform that allows you to connect YourGPT with hundreds of other applications without coding." type="tip" />

To integrate YourGPT with viaSocket, you need to generate an API key for YourGPT and establish a connection between YourGPT and viaSocket.

Make sure you have:

- A YourGPT account: [Sign up here](https://app.yourgpt.ai/login)
- A viaSocket account: [Sign up here](https://app.viasocket.com/)

## Integration Process

<ol className="space-y-8 my-8 list-decimal list-inside">

<li className="space-y-3">
<span className="font-bold dark:text-gray-300 text-lg md:text-xl">Generate a YourGPT API Key</span>

<div className="ml-6 space-y-2">

- Log in to your <a href="https://app.yourgpt.ai/login" target="_blank" rel="noreferrer">YourGPT Dashboard</a>
- Go to Integrations and find API Integration
- Click <strong>Generate API key</strong> and copy the key for use in viaSocket

</div>
</li>

<li className="space-y-3">
<span className="font-bold dark:text-gray-300 text-lg md:text-xl">Connect YourGPT to viaSocket</span>

<div className="ml-6 space-y-2">

- Open your <a href="https://app.viasocket.com/" target="_blank" rel="noreferrer">viaSocket dashboard</a>
- Go to Connections and click <strong>Connect new apps</strong>
- Search for YourGPT in the list of available apps
- Select YourGPT and paste your copied API key into the connection form
- Save to authenticate and establish the connection

</div>
</li>

<li className="space-y-3">
<span className="font-bold dark:text-gray-300 text-lg md:text-xl">Use YourGPT in viaSocket Flows</span>

<div className="ml-6 space-y-2">

- Once connected, YourGPT will be available as an app in your viaSocket flows
- Add YourGPT actions such as <strong>Create Session</strong> and <strong>Send Message</strong> to your flows
- Map required fields like <code>widget_uid</code>, <code>session_uid</code>, and your message content

</div>
</li>

<li className="space-y-3">
<span className="font-bold dark:text-gray-300 text-lg md:text-xl">Edit or Update the Connection (Optional)</span>

<div className="ml-6 space-y-2">

- To update your API key or connection details, go to <strong>Connections</strong> in viaSocket
- Click <strong>Edit</strong> on the YourGPT connection and update as needed
- Save your changes to apply them across your flows

</div>
</li>

</ol>

<Callout title="Once your connection is established, you can immediately use the YourGPT app inside your viaSocket flows." type="tip"/>
