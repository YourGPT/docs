To create a chatbot for Telegram, you can use the BotFather platform. BotFather is the official bot creation platform provided by Telegram.

Here are the steps to create a chatbot using BotFather:

<ol>
  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Open Telegram</div>
    - Open Telegram and search for <strong><code>BotFather</code></strong> in the search bar.
  </li>

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Start a Chat</div>
    - Start a chat with BotFather by clicking on the <strong><code>Start</code></strong> button.
  </li>

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Create a Bot</div>
    - Follow the instructions provided by BotFather to <strong><code>create a new bot</code></strong>.
  </li>

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Get API Token</div>
    - Once the bot is created, BotFather will provide you with an API token. Make sure to save this token as you will need it to interact with your bot.

    <div className="flex justify-center items-center rounded-md px-4 md:px-36 p-4">
      <img
        src="https://chatbot.yourgpt.ai/images/telegram-bot-token.png"
        alt="Slack Flow 1"
        style={{ width: "100%" }}
        className="rounded-md object-contain"
      />
    </div>
  </li>

  <li>
    <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Integrate with YourGPT AI Chatbot</div>
    - Simply <strong><code>paste that token</code></strong> into the Bot Token field within YourGPT AI Chatbot's Telegram integration settings.
  </li>
</ol>

## Integration Supported Types

The Integration ID for Telegram is 10 and the supported types for the integration are as follows:

<Callout title="Supported Types" type="tip">
- Text  
- Image  
<em  className='text-black dark:text-white'>Note: This feature is specifically designed for integration with our platform and may not work as intended when connected with other platforms like Crisp and Intercom.</em>  
- Video  
<em className='text-black dark:text-white'>Note: only supported when integrated with our platform.</em>  
- Audio  
<em className='text-black dark:text-white'>Note: only supported when integrated with our platform.</em>  
- file  
- Button  
- Carousel  
- Card  
</Callout>

<Callout title="Not Supported" type="warning">
- Form
</Callout>
