> Set up and deploy your first YourGPT no-code AI agent.

This guide helps you set up and deploy your first YourGPT AI agent from start to launch. You will move through account creation, agent setup, training, testing, and deployment. Each step links to detailed guides if you want more control later.

## Step 1: Create Your Account

Start by creating a YourGPT account. This gives you access to the dashboard where you manage agents, training data, and integrations.

  

---

## Step 2: Create Your First AI Agent

Create an AI agent and define how it behaves and responds.

At this stage, you will:
- Set the agent persona and tone
- Select the AI model
- Adjust appearance and widget settings
- Add Functions to your agents by allowing them to perform autonomous actions guided by Persona (optional)

  
  
  
  

---

## Step 3: Train Your AI Agent

Train your AI agent using your business data so it can respond accurately.

You can train the agent using:
- Website content
- Files such as PDFs or documents
- Knowledge base links
- Other supported sources

  
  

---

## Step 4: Test Your AI Agent

Before going live, test your agent to verify responses, tone, and behavior. This step helps catch gaps in training or configuration.

  

---

## Step 5: Advanced Configuration

For more control, use AI Studio to build structured flows, connect tools, and design complex agent behavior.

  

---

## Step 6: Deploy Your AI Agent

Once testing looks good, deploy your AI agent where users interact with it.

You can deploy on:
- Websites and web apps
- Messaging and social platforms
- Custom applications using APIs

  
  
  

---

### What’s Next

After deployment, monitor conversations, review logs, and refine training data to improve response quality. As usage grows, you can add more agents, connect additional tools, and expand to new channels from the same dashboard.

If you need help at any step, check the linked guides or reach out to support through the dashboard.
