npm install @yourgpt/widget-web-sdk

```

### 2. AI Actions: Extend Your Chatbot's Capabilities

AI Actions empower YourGPT Copilot to execute specific, meaningful actions within your application, transforming interactions from simple chat to active task execution. These are custom functions your AI agent intelligently invokes to fulfill user requests.

```
const sdk = YourGPT.getInstance();

// Register a custom AI action
sdk.registerAIAction("create_user_account", async (data, helpers) => {
  // Prompt user confirmation before action execution
  const confirmed = await helpers.confirm({
    title: "Create Account",

  } else {

  }
});
```

## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Building AI Actions: Your Copilot's Superpowers </div>

AI Actions are the heart of the Copilot SDK. They let your AI assistant actually *do things* in your application, not just talk about them.

### <div className='text-2xl tracking-tight font-semibold dark:text-inherit text-gray-700'> How AI Actions Work </div>

Think of AI Actions as functions your copilot can call when it understands user intent:

1. **User expresses intent**: "Can you delete my old project files?"
2. **AI recognizes the intent** and calls your registered action
3. **Your action asks for confirmation** (optional but recommended)
4. **Your action performs the task** and reports back
5. **AI responds to user** with the result

### <div className='text-2xl tracking-tight font-semibold dark:text-inherit text-gray-700'> Your First AI Action </div>

Let's start with a simple example - getting the current time:

```typescript title="first-ai-action.ts"
const copilot = YourGPT.getInstance();

copilot.registerAIAction("get_current_time", async (data, helpers) => {
  const currentTime = new Date().toLocaleString();
  helpers.respond(`The current time is ${currentTime}`);
});
```

Now when users ask "What time is it?", your copilot can actually tell them!

### <div className='text-2xl tracking-tight font-semibold dark:text-inherit text-gray-700'> AI Actions with User Confirmation </div>

For actions that change data or cost money, always ask for confirmation:

```typescript title="confirmed-action.ts"
copilot.registerAIAction("upgrade_user_plan", async (data, helpers) => {
  const { planName, price } = JSON.parse(data.action[0].function.arguments);
  
  // Ask user to confirm the action
  const confirmed = await helpers.confirm({
    title: `Upgrade to ${planName}?`,
    description: `This will charge $${price}/month to your account. You can cancel anytime.`,
    acceptLabel: "Upgrade Now",
    rejectLabel: "Not Now"
  });
  
  if (confirmed) {
    try {
      const result = await upgradePlan(planName);
      helpers.respond(`🎉 Successfully upgraded to ${planName}! Your new features are now active.`);
    } catch (error) {
      helpers.respond(`❌ Upgrade failed: ${error.message}. Please try again or contact support.`);
    }
  } else {
    helpers.respond("No problem! You can upgrade anytime from your account settings.");
  }
});
```

Events let you react to what's happening with your copilot in real-time. This is crucial for creating responsive, integrated experiences.

#### **Message Events: React to AI Responses**
```typescript title="message-events.ts"
copilot.onMessageReceived((message) => {
  // Log for analytics
  analytics.track('copilot_message_received', {
    messageType: message.type,
    timestamp: new Date()
  });
  
  // Show notification if widget is closed
  if (!copilot.isOpen()) {
    showNotification("Your AI assistant has a response!");
  }
  
  // Update UI based on AI suggestions
  if (message.suggestions) {
    updateUIWithSuggestions(message.suggestions);
  }
});
```

#### **Human Escalation: Handle Support Handoffs**
```typescript title="escalation-events.ts"
copilot.onEscalatedToHuman((escalationData) => {

  // Update user's support ticket status

  // Show user what to expect

});
```

copilot.onWidgetPopup((isOpen) => {

function SmartActions() {

    aiActions.registerActions({

          title: "Create Project",
          description: `Create "${projectName}" with ${template} template?`
        });
        
        if (confirmed) {
          // Use your existing React functions

          helpers.respond(`✅ Created "${projectName}"! Opening now...`);
          
          // Navigate using React Router
          navigate(`/projects/${project.id}`);
        }
      },
      
      get_user_stats: async (data, helpers) => {
        helpers.respond(`You have ${projects.length} projects and ${user.teamMembers} team members.`);
      }
    });

  }, [projects.length, user.teamMembers]);

## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Advanced Usage & Troubleshooting </div>


Always handle errors gracefully to maintain a positive user experience:

```typescript title="error-handling.ts"
import { YourGPT, YourGPTError } from "@yourgpt/widget-web-sdk";

// Initialization error handling
try {
  await YourGPT.init({
    widgetId: "your-widget-id",
  });
} catch (error) {
  if (error instanceof YourGPTError) {
    console.error("YourGPT initialization error:", error.message, error.code);

    // Display user-friendly message
    showNotification("AI assistant temporarily unavailable. Please try again later.");

    // Report to error tracking system
    reportError("yourgpt_init_failed", { message: error.message, code: error.code });
  } else {
    console.error("Unexpected error during initialization:", error);
  }
}

// AI Action error handling
YourGPT.getInstance().registerAIAction("risky_action", async (data, helpers) => {
  try {
    const result = await performRiskyOperation(data);
    helpers.respond(`✅ Success: ${result.message}`);
  } catch (error) {
    console.error("AI Action failed:", error);
    helpers.respond("❌ Sorry, something went wrong. Our team has been notified.");

    // Report error internally without exposing details to user
    reportError("ai_action_failed", { action: "risky_action", error: error.message });
  }
});
