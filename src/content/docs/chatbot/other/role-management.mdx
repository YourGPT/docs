## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Organisation Roles & Privileges </div>
| Roles | Billing Permissions | Organization Management |
| --- | --- | --- |
| Owner | - Full access to all billing features<br/>- Can manage subscriptions<br/>- Can view plan details | - Full organization management<br/>- Can invite/remove members<br/>- Can update organization details<br/>- Can delete organization<br/>- Can change member roles<br/>- Can revoke invitations |
| Editor | - Can manage subscriptions<br/>- Can view plan details | - Can update organization details<br/>- Can view organization details<br/>- Can view member list |
| Viewer | - Can only view plan details<br/>- No subscription management | - Can view organization details<br/>- Can view member list<br/>- No management permissions |
| Billing | - Full access to all billing features<br/>- Can manage subscriptions<br/>- Can view plan details | - No organization management<br/>- Cannot view organization details<br/>- Cannot view member list |
