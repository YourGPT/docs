##  <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Installation </div>

Integrating YourGPT Chatbot with your Wix website. Follow these simple steps:

<Steps>
 1. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Sign in to Wix:</div>
      - Log in to your Wix account.
 2. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Access the Website Editor:</div>
      - Open your website editor in Wix. 
 3. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Navigate to Settings:</div>
       - From the editor, go to your website's dashboard and click on **Settings**.
  4. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Add Custom Code:</div>
        - In the Settings menu, select **Custom Code**. This allows you to embed scripts or HTML code.
  5. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">YourGPT Chatbot Integration:</div>
      - Visit the YourGPT Chatbot integration page.
      - At the Top part of the screen, locate the **Scripts section** and then Copy the given code snippet.
  6. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Paste the Code:</div>
      - Return to the Wix dashboard's **Custom Code** section and paste the copied code.
  7. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Save Changes:</div>
      - Make sure to save the changes made to the custom code section in Wix.

</Steps>

Congratulations! Your Chatbot is now integrates with your Wix website.
