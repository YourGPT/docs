## Installation

Integrating YourGPT Chatbot with your Wix website. Follow these simple steps:

1. **Sign in to Wix:** Log in to your Wix account.

2. **Access the Website Editor:** Open your website editor in Wix.

3. **Navigate to Settings:** From the editor, go to your website's dashboard and click on **Settings**.

4. **Add Custom Code:** In the Settings menu, select **Custom Code**. This allows you to embed scripts or HTML code.

5. **YourGPT Chatbot Integration:**
   - Visit the YourGPT Chatbot integration page.
   - At the Top part of the screen, locate the **Scripts section** and then Copy the given code snippet. 

6. **Paste the Code:** Return to the Wix dashboard's **Custom Code** section and paste the copied code.

7. **Save Changes:** Make sure to save the changes made to the custom code section in Wix.

Congratulations! Your Chatbot is now integrates with your Wix website.
