## <span  className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Generating Token for WooCommerce (Chatbot Studio) </span>

To generate a WooCommerce API token, you need to follow these steps:

<Steps>
 1. <div className="font-bold dark:text-gray-300 text-xl">Log in to Your WordPress Account</div>
 
 2. <div className="font-bold dark:text-gray-300 text-xl">Go to the Admin Panel</div>
     
          <div className="flex justify-center items-center bg-blue-500 rounded-md p-4 ">
          <Image
            src= "/assets/chatbot/wordpress/wordpress1.png"
            alt= "Admin Panel"
             width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md object-contain"
          />
            </div>

 3. <div className="font-bold dark:text-gray-300 text-xl">Install Woo-Commerce Plugin</div>
 4. <div className="font-bold dark:text-gray-300 text-xl">Now go to `WooCommerce -> settings -> advance -> rest-api.`</div>
 5. <div className="font-bold dark:text-gray-300 text-xl">Click on Add Key</div> 
       <div className="flex justify-center items-center bg-blue-500 rounded-md p-4">
     <Image
      src= "/assets/chatbot/wordpress/wordpress2.png"
      alt= "Add Key"
       width="100%"
       height="100%"
               style={{ width: "100%" }}
               className="rounded-md  object-contain"
      />
      </div>

 6. <div className="font-bold dark:text-gray-300 text-xl">Fill in the necessary details</div>
            - <div className="text-base text-gray-700 dark:text-white/80">
                  <p>
                     Select **Read/Write** for permissions if you want the API key to have both read and write access.
                  </p>
                  </div>
         
          <div className="flex justify-center items-center bg-blue-500 rounded-md p-4">
                  <Image
                     src= "/assets/chatbot/wordpress/wordpress3.png"
                     alt= "Add Key"
                     width="100%"
                     height="100%"
                              style={{ width: "100%" }}
                              className="rounded-md object-contain"
                     />    
            </div> 
 
 7. <div className="font-bold dark:text-gray-300 text-xl">Click Generate API Key</div>
 8. <div className="font-bold dark:text-gray-300 text-xl">You will now see a QR code, a Consumer Key, and a Consumer Secret.</div>
       - You can use these details to authenticate your application with your WooCommerce store.
</Steps>


<Note type="note" color="emerald" >
 Remember to store this information securely, as it won't be shown again for security reasons.
</Note>
