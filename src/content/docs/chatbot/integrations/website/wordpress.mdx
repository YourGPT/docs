## Installation

1. **Log in to WordPress Admin Panel**: Sign in to your WordPress admin panel.

2. **Go the Plugins Section**: Navigate to Plugins section from the WordPress dashboard.



   <Image
   src = "/assets/chatbot/wordpress/2.png"
   alt = "Add Plugin"
   />

3. **Download**: Download the source.zip for Chabot Package from [**YourGPT Github**](https://github.com/YourGPT/yourgpt-chatbot-wordpress-plugin/releases/tag/v1.0.0).

4. **Upload package**: Now upload the package to wordpress

   <Image
   src = "/assets/chatbot/wordpress/3.png"
   alt = "Upload"
   />

5. **Activate Plugin**: Click on Activate button to activate your Plugin

   <Image

   src = "/assets/chatbot/wordpress/4.png"
   alt = "Activate Plugin"
   />

  <Image 
  src = "/assets/chatbot/wordpress/5.png"
  alt = "Click on Setup"
  />
   

6. **YourGPT Chatbot Integration**: Visit the YourGPT [Chatbot integration page](https://chatbot.yourgpt.ai/dashboard) copy the widget id and add it in WordPress.


7. **Paste Widget Id**: Paste the widget id on wordpress settings

<Image
src= "/assets/chatbot/wordpress/6.png"

/>

<Image
src= "/assets/chatbot/wordpress/7.png"

Congratulations! YourGPT Chatbot is now successfully integrated into your WordPress website.

## Generating Token for WooCommerce (Chatbot Studio)

To generate a WooCommerce API token, you need to follow these steps:

1. Log into your WordPress account.
2. Go to the admin panel section.

<Image
src= "/assets/chatbot/wordpress/wordpress1.png"
alt= "Admin Panel"
/>

3. Install Woo-Commerce Plugin.
4. Now go to `WooCommerce -> settings -> advance -> rest-api.`

5. Click **Add Key**.


<Image
src= "/assets/chatbot/wordpress/wordpress2.png"
alt= "Add Key"
/>

6. Fill in the necessary details. Select **Read/Write** for permissions if you want the API key to have both read and write access.


<Image
src= "/assets/chatbot/wordpress/wordpress3.png"
alt= "Add Key"
/>

7. Click **Generate API Key**.
8. You will now see a QR code, a Consumer Key, and a Consumer Secret. You can use these details to authenticate your application with your WooCommerce store.

> **📌 Note:** Remember to store this information securely, as it won't be shown again for security reasons.
