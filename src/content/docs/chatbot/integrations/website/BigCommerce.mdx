## Installation

Integrating YourGPT Chatbot with your BigCommerce store is a straightforward process that enhances customer interaction. Follow these steps:

### Adding the Chat Widget to BigCommerce


1. Log in to your BigCommerce admin panel.

<Image 
  src="/assets/chatbot/bigcommerce/Commerece1.png"
  alt="Create a BigCommerce"
/>

2. Go to **Storefront** > **Script Manager**.

<Image 
  src="/assets/chatbot/bigcommerce/Commerce2.png"
  alt="The Theme Manager"
/ >

3. Click on **Create a script**.


<Image 
  src="/assets/chatbot/bigcommerce/Commerce3.png"
  alt="Storefront"
/>
4. Go to the **Integrations** section and copy the script for the Widget.


5. Fill out the script details:
   - **Name**: Enter a name for your script (e.g., "YourGPT Chatbot")
   - **Description**: Add an optional description
   - **Location**: Select "Footer"
   - **Select pages where script will be added**: Choose "All pages"


6. Configure the script:
   - **Script category**: Choose a category or leave as default
   - **Script type**: Select "Script"
   - **Script contents**: Paste the copied YourGPT code
   - Remove the first line and last two lines of the pasted code

<Image 
  src="/assets/chatbot/bigcommerce/Commerce4.png"
  alt="Add The Script"
/>

9. Click **Save** to add the script to your store.

10. Use the **View Store** button to verify that the chatbot appears on your website.

Congratulations! YourGPT Chatbot is now integrated into your BigCommerce store.
