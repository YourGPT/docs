## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'>  Installation </div>

Integrating YourGPT Chatbot with your BigCommerce store is a straightforward process that enhances customer interaction. Follow these steps:

### <div className='text-2xl tracking-tight font-semibold dark:text-inherit text-gray-700'>  Adding the Chat Widget to BigCommerce </div>

<Steps>
1. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Log in to your BigCommerce admin panel:</div>
   - Log in to your BigCommerce admin panel.
   <div className="flex justify-center items-center bg-blue-500 rounded-md p-4 md:p-6">
          <Image
          src="/assets/chatbot/bigcommerce/Commerece1.png"
          alt="Create a BigCommerce"
           width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md object-contain"
        />
        </div>
2. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Go to Storefront > Script Manager:</div>
    - Go to **Storefront** > **Script Manager**.
    <div className="flex justify-center items-center bg-blue-500 rounded-md p-4 md:p-6">
    <Image
          src="/assets/chatbot/bigcommerce/Commerce2.png"
          alt="Create a BigCommerce"
           width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md object-contain"
        />
        </div>
3. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Click on Create a script:</div>
    - Click on **Create a script**.
    <div className="flex justify-center items-center bg-blue-500 rounded-md p-4 md:p-6">
    <Image src="/assets/chatbot/bigcommerce/Commerce3.png" alt="Storefront"  width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md" />
        </div>

4. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Go to the Integrations section and copy the script for the Widget:</div>
    - Go to the **Integrations** section and copy the script for the Widget.
5. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Fill out the script details:</div>
    - **Name**: Enter a name for your script (e.g., "YourGPT Chatbot")
    - **Description**: Add an optional description
    - **Location**: Select "Footer"
    - **Select pages where script will be added**: Choose "All pages" 
6. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Configure the script:</div>
    - **Script category**: Choose a category or leave as default
    - **Script type**: Select "Script"
    - **Script contents**: Paste the copied YourGPT code
    - Remove the first line and last two lines of the pasted code
    <div className="flex justify-center items-center bg-blue-500 rounded-md p-4 md:p-6">
    <Image src="/assets/chatbot/bigcommerce/Commerce4.png" alt="Add The Script" width="100%" height="100%"
               style={{ width: "100%" }}
               className="rounded-md" />
        </div>

9. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Click Save to add the script to your store:</div>
    - Click **Save** to add the script to your store.
10. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Use the View Store button to verify that the chatbot appears on your website:</div>
    - Use the **View Store** button to verify that the chatbot appears on your website.

</Steps>

Congratulations! YourGPT Chatbot is now integrated into your BigCommerce store.
