## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Installation </div>

Integrating GPT Chatbot with your Shopify store is a seamless process that enhances customer interaction. Follow these steps:

## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Install Chatbot App </div>

1. Go to the **YourGPT Integration** section and copy the provided widget script.
2. Log in to your Shopify admin panel.
3. Navigate to your store's theme code.
4. Paste the widget script into the appropriate section of your theme code.
5. Save the changes to implement the chatbot.


## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Generating Token for Shopify (Chatbot Studio) </div>

To generate a Shopify Auth Token, you need to follow these steps:

<Steps>
1. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Create a new app in your Shopify admin panel.</div>
     - You can do this by going to **Apps -> apps and sales channel -> Develop apps -> create an app**.
2. <div className="font-bold dark:text-gray-300 text-lg md:text-xl"> Fill in the app details. </div>
      - You can use any name and email you like.
3. <div className="font-bold dark:text-gray-300 text-lg md:text-xl"> After creating the app, go to Configure Admin API scopes. </div>
   <Image src="/assets/chatbot/shopify/Shopify-flow-1.png" alt="Shopify Admin API Configuration" width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md" />
4. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Select the scopes mentioned above and click the save button. </div>
    <Image src="/assets/chatbot/shopify/Shopify-flow-2.png" alt="Shopify API Scopes Selection" width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md" />
5. <div className="font-bold dark:text-gray-300 text-lg md:text-xl"> After that, install the app and click on **Reveal token once** you will get your token.  </div>
     <Image src="/assets/chatbot/shopify/Shopify-flow-3.png" alt="Shopify Auth Token Reveal" width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md" />

</Steps>



It is crucial to securely store your Auth Token as it provides access to your Shopify administration.
