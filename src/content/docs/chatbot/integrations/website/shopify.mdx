## Installation

Integrating GPT Chatbot with your Shopify store is a seamless process that enhances customer interaction. Follow these steps:

### Install Chatbot App

1. Log in to your Shopify admin panel.
2. Navigate to the Apps section from the left-hand menu.
3. Click on **Visit Shopify App Store**.
4. Search for YourGPT Chatbot.
5. Select **YourGPT Chatbot** from the search results and click Add app.
6. Follow the prompts to install the app to your Shopify store.

### Post-Installation Configuration

1. Once the app is installed, access the app dashboard.
2. Create your personalised chatbot by visiting [**GPT Chatbot Builder**](https://yourgpt.ai/chatbot).
3. In the **Integration** section of YourGPT Chatbot's dashboard, copy the Widget Id and Chatbot Id assigned specifically to your store.
4. Return to the YourGPT Chatbot app in your Shopify admin panel.
5. Paste the acquired **Widget Id and Chatbot Id** into the respective fields within the app settings.
6. Save the changes.

## Generating Token for Shopify (Chatbot Studio)

To generate a Shopify Auth Token, you need to follow these steps:

1. Create a new app in your Shopify admin panel. You can do this by going to **Apps -> apps and sales channel -> Develop apps -> create an app**.

2. Fill in the app details. You can use any name and email you like.

3. After creating the app, go to Configure Admin API scopes.

<Image src="/assets/chatbot/shopify/Shopify-flow-1.png" alt="Shopify Admin API Configuration" />

4. Select the scopes mentioned above and click the save button.

<Image src="/assets/chatbot/shopify/Shopify-flow-2.png" alt="Shopify API Scopes Selection" />

5. After that, install the app and click on **Reveal token once** you will get your token.

<Image src="/assets/chatbot/shopify/Shopify-flow-3.png" alt="Shopify Auth Token Reveal" />


It is crucial to securely store your Auth Token as it provides access to your Shopify administration.
