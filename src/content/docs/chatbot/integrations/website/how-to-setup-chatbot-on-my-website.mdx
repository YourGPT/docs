## Installation

Integrating YourGPT Chatbot with your HTML website. Follow these simple steps:

1. **Access Your HTML Website:** Open your HTML website in the editor of your choice.

2. **Copy the Widget Code:** Visit the [**```YourGPT Chatbot```**](https://yourgpt.ai/chatbot) -> **```Access your chatbot```** -> Go to Integration page and **```copy the code```** located in the script section at the top of your screen.

3. **Add Widget Code to Head Tag:** Insert the provided script code for your Chatbot in your HTML code.

4. **Save Changes:** Ensure to save the changes made to your HTML code editor.

Congratulations! Your Chatbot is now integrated with your HTML website.
