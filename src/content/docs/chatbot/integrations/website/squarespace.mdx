## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Installation </div>

Integrating YourGPT Chatbot with your Squarespace website. Follow these simple steps:

<Steps>
 1. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Sign in to Squarespace:</div>

      - Log in to your Squarespace account.
  2. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Open Website Editor:</div>
      - In the top left corner, select **`EDIT`**.
  
      <div className="flex justify-center items-center bg-blue-500 rounded-md p-4  ">
        <Image 
            src="/assets/chatbot/squarespace/squarespace1.png"
            alt="Install"
            width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md object-contain "
          />
        </div>

  3. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Edit Footer:</div>
       - Scroll down until you see the **`EDIT FOOTER`** button, click on it. Now click on the **`ADD BLOCK`** button in the left-hand corner,.

      <div className="flex justify-center items-center bg-blue-500 rounded-md p-4  ">
        <Image 
            src="/assets/chatbot/squarespace/squarespace2.png"
            alt="Install"
            width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md object-contain "
          />
        </div>

  4. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Add Embed Block:</div>
  
        - Then select the **`Code`** option.

      <div className="flex justify-center items-center bg-blue-500 rounded-md p-4  ">
        <Image 
            src="/assets/chatbot/squarespace/squarespace3.png"
            alt="Install"
            width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md object-contain "
          />
        </div>

  5. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Edit Embed Block:</div>
      - Click to **`Edit`** and then select the **`Code Snippet`** option.


      <div className="flex justify-center items-center bg-blue-500 rounded-md p-4  ">
        <Image 
            src="/assets/chatbot/squarespace/squarespace4.png"
            alt="Install"
            width="100%"
             height="100%"
               style={{ width: "100%" }}
               className="rounded-md object-contain "
          />
        </div>

  6. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">YourGPT Chatbot Integration:</div>
      - Visit the YourGPT Chatbot integration page.
      - Copy the provided code snippet from the **`Scripts section`**.
  7. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Paste the Code:</div>
      - Paste the chatbot widget `Script` code into the Block.
  8. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Save Changes:</div>
      - Save your changes and then select **`DONE`**.

</Steps>

The ChatBot’s chat widget should now appear on your website.
