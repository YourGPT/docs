## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Installation </div>

<Steps>
1. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Get Widget Code:</div>
    - Sign in to your <a href="https://chatbot.yourgpt.ai/" className="font-bold no-underline">YourGPT dashboard</a>
    - Go to Integration section
    - Copy the widget code provided for your chatbot

2. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Access Framer Project:</div>
    - Log in to your Framer account
    - Navigate to your project dashboard
    - Select your target website project

3. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Locate Page Settings:</div>
    - Find your desired page in the left panel
    - Click the three-dot icon next to the page name
    - Select "Settings" from the menu

4. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Access Custom Code Section:</div>
    - Scroll down in Settings
    - Locate the "Custom Code" section

5. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Add Widget Code:</div>
    - Paste your copied YourGPT widget code into the "Start of `<head>` tag" box
    - Click "Save" in the top right corner

6. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Verify Installation:</div>
    - View your page
    - Look for the YourGPT chatbot icon in the bottom left corner
    - Test the chatbot functionality
</Steps>

## <div className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'> Troubleshooting </div>

If the chatbot isn't appearing:
- Verify the code was pasted in the correct section (Start of `<head>` tag)
- Ensure you clicked the Save button
- Clear your browser cache and refresh the page
- Check if your YourGPT account is active
