<Aside type="tip" title="Idea"> 💡 Connecting Your AI Chatbot with Intercom </Aside>

Intercom integration allows seamless communication between YourGPT AI Bot and Intercom, enabling efficient customer interactions.

## <span  className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'>Prerequisites</span>

<div className="text-base text-gray-700 dark:text-white/80">
  <p>
    <strong>1.</strong> Create an account on Intercom at 
    <a href="https://app.intercom.com/" className="font-bold " target="_blank"> ***`app.intercom`***</a>
  </p>
  <p>
    <strong>2.</strong> Enable Intercom from YourGPT dashboard at 
    <a href="https://chatbot.yourgpt.ai/" className="font-bold" target="_blank"> ***`chatbot.yourgpt`***</a>
  </p>
  <p>
    <strong>3.</strong> Create an Intercom developer account at 
    <a href="https://developers.intercom.com/" className="font-bold" target="_blank"> ***`developers.intercom`***</a>
  </p>
</div>


## <span  className='text-3xl tracking-tight font-bold dark:text-inherit text-gray-700'>Integration Steps</span>

<Steps>
1. <div className="font-bold dark:text-gray-300 text-xl">Create an Intercom App</div>
     - Log in to your Intercom developer account.
     - Create the app that you want to integrate with.
    <div className="flex justify-center items-center bg-blue-500 rounded-md p-4">
     <Image src="/assets/chatbot/Intercom/make-app.gif" 
     alt="Create Intercom Apps"
     height="100%"
         width="100%"
         style={{ width: "100%" }}
         className="rounded-md"
         />
      </div>

2. <div className="font-bold dark:text-gray-300 text-xl">Obtain App ID and Access Token</div>
     - Copy the **`App ID`** and **`Access Token`** from your Intercom app settings.
     <div className="flex justify-center items-center bg-blue-500 rounded-md p-4">
     <Image src="/assets/chatbot/Intercom/intercom4-5.png" 
     alt="Copy App ID and Access Token"
     height="100%"
         width="100%"
         style={{ width: "100%" }}
         className="rounded-md"
         />
      </div>

3. <div className="font-bold dark:text-gray-300 text-xl">Paste Credentials in YourGPT Dashboard</div>
     - Paste the copied **`App ID`** and **`Access Token`** into the YourGPT dashboard.
     <div className="flex justify-center items-center bg-blue-500 rounded-md p-4">
     <Image src="/assets/chatbot/Intercom/intercom1.png" 
     alt="YourGPT Dashboard"
     height="100%"
         width="100%"
         style={{ width: "100%" }}
         className="rounded-md"
         />
      </div>
     <div className="flex justify-center items-center bg-blue-500 rounded-md p-4 md:p-12">
     <Image src="/assets/chatbot/Intercom/intercom5.png" 
     alt="Paste Credentials in YourGPT Dashboard"
     height="100%"
         width="100%"
         style={{ width: "100%" }}
         className="rounded-md object-contain"
         />
      </div>

4. <div className="font-bold dark:text-gray-300 text-xl">Configure Webhook</div>
     - Add a webhook URL and generate it in the Intercom app webhook settings.
    <div className="flex justify-center items-center bg-blue-500 rounded-md p-10">
     <Image src="/assets/chatbot/Intercom/intercom6.png" 
     alt="Configure Webhook"
     height="100%"
         width="100%"
         style={{ width: "100%" }}
         className="rounded-md object-contain"
         />

    </div>

5. <div className="font-bold dark:text-gray-300 text-xl">Verify Webhook</div>
     - Confirm the successful addition of the webhook. You will receive a confirmation message.
     <div className="flex justify-center items-center bg-blue-500 rounded-md p-4">
     <Image src="/assets/chatbot/Intercom/intercom7.png" 
     alt="Chat Integration"
     height="100%"
         width="100%"
         style={{ width: "100%" }}
         className="rounded-md"
         />
      </div>

6. <div className="font-bold dark:text-gray-300 text-xl">Chat Integration (Optional)</div>
      - For more customization and control, implement Canvas kit.
      - Initialize flow webhook URL:
  
      ```
      https://api.yourgpt.ai/chatbot/v1/intercom/canvas/{your app_id}
      
      ```
  
      - Submit flow webhook URL:
  
      ``` 
      https://api.yourgpt.ai/chatbot/v1/intercom/canvas/webhook/{your app_id}
      
       ```
      <div className="flex justify-center items-center bg-blue-500 rounded-md p-4">
      <Image src="/assets/chatbot/Intercom/intercom8.png" 
      alt="Chat Integration"
      height="100%"
          width="100%"
          style={{ width: "100%" }}
          className="rounded-md"
          />  
      </div>
      
</Steps>
