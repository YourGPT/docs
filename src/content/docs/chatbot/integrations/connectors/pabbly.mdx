<Aside type="tip">
  Pabbly Connect is a powerful workflow automation platform that allows you to connect YourGPT with hundreds of other applications without coding.
</Aside>

## Before You Begin

Before starting the integration process, make sure you have:

- A YourGPT account: [Sign up here](https://app.yourgpt.ai/login)
- A Pabbly Connect account (free or paid)

## Integration Process

<Steps>
  1. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Connect to Pabbly</div>
  
      - Log in to your [Pabbly Connect account](https://connect.pabbly.com/)
      - Search for "**YourGPT Chatbot**" in the Pabbly Connect app directory
      - Select and connect your "YourGPT Chatbot" to Pabbly Connect
      
  2. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Set Up API Authentication</div>
  
      - Head over to [YourGPT Dashboard](https://app.yourgpt.ai/login)
      - Navigate to **Integrations ⇒ API Integration ⇒ Generate API key**
      - Copy your API key for use in Pabbly Connect
      
      <Aside type="note">
        For detailed instructions on generating API keys, visit the [API Integration Guide](/chatbot/integrations/api-integration#generating-keys)
      </Aside>

  3. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Create a Session</div>
  
      - In your workflow, add a new action and select "YourGPT Chatbot"
      - Choose **`"Create Session"`** as the action
      - Provide the **`widget_uid`** in the action setup
      - The `widget_uid` can be found in your **YourGPT Chatbot Integrations**
      
      <div className="flex justify-center items-center bg-blue-500 rounded-md p-4 mt-4">
        <Image src="/assets/chatbot/pabbly/widgetid-pabbly-integration.png" alt="Widget UID location in YourGPT" 
               width="100%" height="100%" style={{ width: "100%" }} 
               className="rounded-md object-contain shadow-lg" />
      </div>
      
      <Note>
        The Create Session action initializes a conversation with your YourGPT chatbot and returns a `session_uid` that you'll need for sending messages.
      </Note>
      
  4. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Send a Message</div>
  
      - Add another **"YourGPT Chatbot"** action to your workflow
      - Select **"Send Message"** as the action
      - Configure the following parameters:
        - `widget_uid`: The same ID used in the Create Session action
        - `message`: The text content you want to send
        - `session_uid`: Map this from the output of the Create Session action
      
  5. <div className="font-bold dark:text-gray-300 text-lg md:text-xl">Test and Deploy</div>
  
      - Test your workflow thoroughly to ensure all actions work correctly
      - Once tested, you can activate your workflow for production use
      - Consider adding error handling for robustness
</Steps>
